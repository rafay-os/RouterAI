# October 19, 2026: Designed schematic and power routing for ESP32-S3 AI Node
<!-- fabricate:entry 681 -->

Designed the custom PCB schematic for a self-hosted local AI voice assistant.

- Configured I2S audio routing between ESP32-S3, INMP441 mic, and MAX98357A amplifier.
- Set up DC barrel jack power management using an external step-down buck converter module for a stable 5V rail.
- Completed net labeling, verified DRC checks in EasyEDA, and prepared layout for PCB routing.
